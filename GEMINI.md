## Antigravity / Gemini specifics
- Work one ticket at a time from `docs/TICKETS.md`. Create a short plan first (files to touch, tests to write) and wait for approval before large changes.
- Keep the artifacts you produce (plans, task lists, walkthroughs) consistent with `context/progress-tracker.md`; the tracker file in the repo is the source of truth.
- Do not rely on browser or external research to override a decision in `docs/`. Use it only to verify facts such as a crate's current API or an agent CLI's current flags, and record findings in `BRAIN.md`.
- Run the checks listed in `AGENTS.md` before reporting a ticket as done.
- Never run destructive terminal commands without explicit approval.
